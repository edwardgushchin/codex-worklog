# Governance

Codex Worklog is maintained as an open-source project with a lightweight maintainer-led model.

## Roles

### Maintainer

The maintainer is responsible for:

- technical direction and lifecycle compatibility;
- security response and coordinated disclosure;
- issue and pull request triage;
- release approval and marketplace metadata;
- Code of Conduct enforcement.

The initial maintainer is [Eduard Gushchin](https://github.com/edwardgushchin).

### Contributors

Contributors may propose changes, review pull requests, improve documentation, reproduce defects, and help other users. Sustained contributors may be invited to take on triage or maintenance responsibilities.

## Decisions

Routine decisions are made through issues and pull requests using technical evidence, user impact, portability, privacy, and maintenance cost. Breaking file-format, lifecycle, security, or privacy changes require an issue before implementation.

The maintainer makes the final decision when consensus is not reached. Decisions that materially affect users should be recorded in the issue, pull request, documentation, and changelog.

## Changes to Governance

Governance changes are proposed through a pull request and should explain the motivation, transition plan, and effect on existing contributors.
